# Game Product Management & Monetization Skill

本技能为休闲游戏产品设计、核心循环 (Core Loop)、玩家留存率提高与高转化商业化付费变现模型指南。

---

## 1. 核心游戏循环 (Core Game Loop & Habit Loop)

成功的休闲游戏必须建立清晰自洽的闭环体系：

```
┌────────────────────────────────────────────────────────┐
│                    核心玩法 (Gameplay)                  │
│               例如：消消除、贪吃蛇、防塔、卡牌             │
└───────────────────────────┬────────────────────────────┘
                            │ 获得关卡奖励
                            ▼
┌────────────────────────────────────────────────────────┐
│                   金币 / 资源 / 经验                    │
└───────────────────────────┬────────────────────────────┘
                            │ 消耗资源
                            ▼
┌────────────────────────────────────────────────────────┐
│                 数值成长 / 皮肤 / 技能解锁              │
└───────────────────────────┬────────────────────────────┘
                            │ 提升战斗力/挑战更高关卡
                            ▼
┌────────────────────────────────────────────────────────┐
│                 更高难度挑战 / 排行榜榜单                │
└────────────────────────────────────────────────────────┘
```

## 2. 玩家留存策略 (Player Retention System)

### 2.1 7 天签到与连续奖励 (Daily Login & Streak Bonus)

设置“梯度递增”的签到奖励，第 3 天与第 7 天放置高价值稀有物品/皮肤，利用“损失厌恶”提升 D1/D7 留存：

```javascript
const DAILY_REWARDS = [
  { day: 1, reward: '100 金币', icon: '🪙' },
  { day: 2, reward: '双倍积分卡 x1', icon: '⚡' },
  { day: 3, reward: '稀有皮肤：霓虹炫光', icon: '✨' },
  { day: 4, reward: '250 金币', icon: '🪙' },
  { day: 5, reward: '复活卡 x2', icon: '💖' },
  { day: 6, reward: '500 金币', icon: '💰' },
  { day: 7, reward: '限定终极战机 / 尊贵称号', icon: '👑' }
];
```

### 2.2 任务与成就系统 (Quests & Achievements)

- **每日任务 (Daily Quests)**: 完成 3 局游戏、累计获得 1000 分、分享游戏 1 次。
- **成就树 (Achievement Tree)**: 长期目标（如“得分突破 10,000 分”），给予大额代币奖励。

### 2.3 离线收益 (Idle / Offline Earnings)

玩家离线期间按时间自动累计金币（上限 8~12 小时），上线时可点击“免费领取”或**“看广告获取 3 倍离线收益”**。

## 3. 商业化变现模型 (Monetization Architecture)

### 3.1 激励视频广告 (Rewarded Video Ads - 转化率最高)

激励广告不会打断游戏体验，玩家自愿观看以换取高价值回报：

1. **对局失败“原地复活”**: 游戏结束时提供 1 次看广告复活机会（保留当前得分）。
2. **结算奖励“翻倍”**: 游戏结算界面提供“看广告收益 2 倍 / 3 倍”按钮。
3. **试用高级皮肤/道具**: 允许玩家看 1 次广告免费体验限时超级道具 1 局。
4. **补充体力/精力**: 当体力耗尽时，提供“观看广告恢复 3 点体力”。

### 3.2 应用内内购 (In-App Purchases / IAP)

1. **首充礼包 (First Purchase Anchor)**: 极其划算的低价礼包（如 $0.99），打破玩家付费心理防线。
2. **通行证 (Battle Pass / Season Pass)**: 提供免费版与付费高级版（VIP Pass），通过持续玩游戏解锁赛季限定内容。
3. **外观与个性化 (Cosmetics & Customization)**: 炫酷拖尾、限定皮肤、专属头像框（不影响数值平衡，但极具社交炫耀价值）。
4. **抽奖 / 幸运转盘 (Lucky Wheel / Gacha)**: 每天 1 次免费抽奖机会，后续消耗代币或观看广告继续抽奖。

## 4. 关键数据指标 (Analytics & KPI Metrics)

评估游戏健康度与商业化能力的黄金指标：

| 指标名称 | 含义说明 | 目标优秀基准值 (Benchmark) |
| :--- | :--- | :--- |
| **D1 Retention** | 次日留存率 | > 40% |
| **D7 Retention** | 7 日留存率 | > 15% - 20% |
| **DAU / MAU** | 活跃用户黏性 | > 20% |
| **ARPU** | 每用户平均收入 | 根据广告 eCPM & 付费率优化 |
| **ARPPU** | 每付费用户平均收入 | 评估中重度付费玩家拉动力 |
| **Ad Imp/DAU** | 人均广告展示次数 | 休闲游戏 3 ~ 5 次 / 日 |
